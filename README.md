# TopDawgs Mobile App — GitHub Pages Prototype (v18.0)

This repository contains the GitHub-ready PWA mockup for the **TopDawgs Mobile App** built directly from master specification v18.0.

## How to Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g., `topdawgs-mobile-app`).
2. Add all six files (`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `README.md`) to your local folder.
3. Push the files to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Deploy TopDawgs v18.0 PWA Mockup"
   git branch -M main
   git remote add origin [https://github.com/YOUR_USERNAME/topdawgs-mobile-app.git](https://github.com/YOUR_USERNAME/topdawgs-mobile-app.git)
   git push -u origin main
